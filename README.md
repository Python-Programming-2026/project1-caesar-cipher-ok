# 凯撒密码工具 README

## 项目介绍
这是一个基于 Python 实现的**凯撒密码（Caesar Cipher）** 加密/解密工具，支持对字母字符进行指定偏移量的加密和解密操作，非字母字符（数字、空格、标点等）保持不变，同时区分大小写字母。

## 程序部署过程
### 1.部署前置准备
文本编辑器：准备任意文本编辑器，用于保存代码文件。
### 2.部署步骤
代码保存：在文本编辑器中写代码，保存为 Caesar.py。
部署完成：直接进入交互式使用环节。

## 功能特点
- 支持字母的加密/解密，区分大小写
- 非字母字符（数字、空格、标点）不做处理，原样保留
- 支持自定义偏移量（整数），偏移量超出字母表范围时自动循环（如 Z 偏移 1 变为 A）
- 交互式命令行操作，使用简单

## 环境要求
- Python 3.x（兼容所有 3.x 版本，无需额外安装依赖）

## 使用方法

### 1. 运行程序
将代码保存为 `Caesar.py`，在终端/命令行中执行：
```bash
python Caesar.py
```

### 2. 交互步骤
1. 程序启动后显示 `=== 凯撒密码工具 ===` 提示；
2. 输入模式：
   - 加密：输入 `encrypt`
   - 解密：输入 `decrypt`
3. 输入需要处理的文本（支持任意包含字母、数字、符号的字符串）；
4. 输入偏移量（整数，如 `3`、`5`、`-2` 等）；
5. 程序输出加密/解密结果。

### 3. 示例演示

#### 示例 1：加密
```
=== 凯撒密码工具 ===
请选择模式（encrypt 加密 / decrypt 解密）：encrypt
请输入要处理的文本：Hello, World!
请输入偏移量（数字）：3
加密结果：Khoor, Zruog!
```

#### 示例 2：解密
```
=== 凯撒密码工具 ===
请选择模式（encrypt 加密 / decrypt 解密）：decrypt
请输入要处理的文本：Khoor, Zruog!
请输入偏移量（数字）：3
解密结果：Hello, World!
```

#### 示例 3：偏移量循环（Z 偏移 1 变为 A）
```
=== 凯撒密码工具 ===
请选择模式（encrypt 加密 / decrypt 解密）：encrypt
请输入要处理的文本：Zyx123
请输入偏移量（数字）：1
加密结果：Ayz123
```

## 注意事项
1. 偏移量需输入整数，若输入非数字（如字母、符号）会触发 `ValueError` 错误；
2. 模式输入需严格匹配 `encrypt` 或 `decrypt`（区分大小写），输入错误会提示「模式输入错误」；
3. 偏移量支持负数（如 `-3` 表示字母向前移动 3 位）。

## 扩展建议
1. 增加输入校验：对偏移量非数字的情况做异常处理，避免程序崩溃；
2. 支持模式输入的模糊匹配（如输入「加密」「jiami」也能识别为加密模式）；
3. 增加批量处理功能：支持从文件读取文本并输出加密/解密结果到文件；
4. 增加多语言支持（如对中文拼音字母的处理）。
